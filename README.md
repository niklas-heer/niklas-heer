I lead Platform Engineering at [Tradebyte](https://www.tradebyte.com), where we're building an Internal Developer Platform to help engineering teams ship software with less friction.

Outside work, I build open-source tools with a shared shape: **local-first, one binary, plain files you can read in Git, and usable by people and AI agents alike.** I like small, focused utilities. This occasionally escalates into building a shell, or a programming language.

### Find your next tool

| If you want to… | Take a look at… |
| :--- | :--- |
| **Keep your todos in your repo** | [**tdx**](https://github.com/niklas-heer/tdx): a terminal todo manager with Vim-style navigation. Your tasks stay in plain Markdown. |
| **Launch apps with a key sequence** | [**Keywink**](https://github.com/niklas-heer/Keywink): a native macOS launcher. Type a few letters; the on-screen guide shows the way. Config stays in JSON. |
| **Write Markdown in a calm, native editor** | [**Focal**](https://github.com/niklas-heer/focal): a macOS Markdown editor you open from the terminal. Live rendering, and files are saved exactly as you wrote them. |
| **Remember why you decided something** | [**vrdx**](https://github.com/niklas-heer/vrdx): engineering decision records in Markdown, with a local dashboard and structured context for agents. |
| **Turn architecture into diagrams** | [**Sceno**](https://github.com/niklas-heer/sceno): describe it in KDL, preview locally, export SVG, PDF and slides. Agents can iterate until it validates. |
| **Give an agent credentials without handing over the vault** | [**Latchrun**](https://github.com/niklas-heer/latchrun): scoped sessions from 1Password or pass, approved commands only, replay-safe. |
| **Ship a Python CLI as one binary** | [**Kipferl**](https://github.com/niklas-heer/kipferl): write Python-style scripts, get a fast standalone executable. |
| **Keep every repository on your machine in order** | [**repot**](https://github.com/niklas-heer/repot): a predictable home for every checkout, parallel fetches, a status report, and a fuzzy picker to jump between them. |
| **Run a team chat on your own server** | [**Sideporch**](https://github.com/niklas-heer/sideporch): channels, threads, polls and search in one Rust binary and one data directory. Imports from Slack. |
| **Explore a different kind of shell** | [**Quirl**](https://github.com/niklas-heer/quirl): familiar Bash commands, typed data pipelines, and Lua extensions. |
| **Try a small new language** | [**Morrow**](https://github.com/morrow-lang/morrow): statically typed and functional, with Python-like syntax, compiled to native programs. |

Each of them has a page with pictures, the story behind it and live numbers at [nheer.com/projects](https://nheer.com/projects).
